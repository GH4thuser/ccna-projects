# Network Security 

Hands-on exploring network configuration, architecture, attack techniques and defenses


## Network Segmentation and Traffic Isolation

Topics covered:
- VLAN-based network segmentation to isolate traffic between departments
- Trunk configuration for carrying multiple VLANs across a single link
- Inter-VLAN routing to control and manage traffic flow between segments
- Practical understanding of how enterprise networks are structured and secured

---

## STP Root Bridge Hijacking and Defense

Topics covered:
- Simulated a real-world Layer 2 attack where a rogue switch hijacks
  the Spanning Tree root bridge election to intercept network traffic
- Demonstrated how an attacker can silently redirect all traffic
  through a malicious device
- Implemented Root Guard as a countermeasure to detect and block
  the attack
- Verified traffic flow before and after the attack and defense
